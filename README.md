# Microphone Voice Control

โปรแกรม สำหรับล็อกและควบคุมระดับเสียงไมโครโฟนบน Windows จาก System Tray

## ฟีเจอร์

- **คลิกซ้าย**: ปิด / เปิดไมค์ทันที (ไอคอนเปลี่ยนเป็นสีแดงเมื่อ Mute)
- **ล็อกความดัง (Volume Lock)**: ดึงเสียงกลับมาค่าเดิมทันทีหากมีแอปอื่นปรับเปลี่ยน
- **ปรับความดังง่าย**: ปรับผ่านเมนูคลิกขวา (0-100% ขยับทีละ 5%) หรือพิมพ์ระบุเลขเอง
- **เลือกไมค์ & สลับภาษา**: รองรับเลือกไมค์รายตัว/ค่าเริ่มต้น และสลับภาษา ไทย / EN
- **เปิดพร้อมเครื่อง**: ติ๊กให้เปิดทำงานอัตโนมัติตอนเปิด Windows ได้

## การใช้งาน

1. เปิดไฟล์ `MicVoiceControl.exe`
2. **คลิกซ้ายที่ไอคอนถาดงาน (System Tray)** = ปิด/เปิดไมค์
3. **คลิกขวาที่ไอคอน** = เมนูตั้งค่าความดัง และเลือกไมค์
